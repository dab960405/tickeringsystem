## D. Historical tests and evidence

### RED tests before fixing

- `DeploymentProfileIT`: with no explicit profile, unexpectedly found three seed accounts instead of zero; `prod` had no demo seed and `dev` used its documented password.
- `DataIntegrityLoggingTest` and `DataIntegrityLoggingIT`: synthetic rejected email appeared in handler log. The JDBC test first confirmed PostgreSQL actually included the email in the underlying error.
- `OrderCreationIntegrityIT`: with an advanced JVM clock got 422 instead of 201; with a lagging JVM clock got 201 instead of 422. Creation could reject a valid sale window when JVM lagged or extend TTL when ahead.
- `PaymentPropertiesTest`: short secret, known placeholder and single-character repeated secret were accepted.
- Environmental caveat: the first unit run could not attach Mockito's agent inside a sandbox, resolved by rerunning with the same JDK outside it. The first profile test's JDBC separator was wrong; that **test fixture** was fixed before claiming results.
- Some red discovery runs used `-Dmaven.test.failure.ignore=true` to collect failures. Their nominal `BUILD SUCCESS` was **not** a pass: Surefire/Failsafe XML failures were reported. Final positive CI omitted the ignore flag.
